# KOVA — descargas

Descargas oficiales de **KOVA**, de KineDigital.

KOVA ordena lo que el día desordena en la atención primaria, para que el equipo
vuelva a lo suyo: atender.

Acá viven **sólo los archivos para descargar**. El código no está en este
repositorio.

## Qué hay en Releases

| Release | Qué trae |
|---|---|
| `videos-2026-09` | Los videos de presentación listos para publicar: vertical 9:16 (estado de WhatsApp, Reels, Stories) y feed 4:5 de Instagram. |
| `masters-2026-09` | Los másteres del mismo video: 4K y HD, horizontal y vertical. Archivos pesados, para editar o reutilizar. |

Todos duran 40 segundos.

## Qué formato usar

- **Vertical 9:16 (1080×1920)** — sirve igual para estado de WhatsApp, Reels y
  Stories. Es el mismo archivo, no hace falta uno por sitio.
- **Feed 4:5 (1080×1350)** — sólo para la publicación del feed de Instagram.
  El cuadro completo va encajado, no recortado: recortar perdía la cabecera de
  marca y el aviso al pie.
- **Másteres 4K / HD, horizontal y vertical** — para editar, subtitular o
  reencuadrar. No para publicar directo: pesan demasiado.

## Sobre lo que se ve en los videos

Las pantallas que aparecen son **funciones ilustradas con datos ficticios**.
No hay información de pacientes reales en ninguna parte de estos archivos.
